# Stage 3 — Voice and messaging

## Voice (3 adjectives)
Each: word · what it means here · do sentence · don't sentence (the don't is the adjective gone wrong). Take do-samples from the user's own writing; if none exist, write them and mark `[draft]` for approval.
Add: sentence length habit, person (I/we), humour allowed?, swearing/jargon policy, emoji policy, punctuation rules (e.g. no em dashes).

## Tone map
| Context | Tone shift | Example opening line |
Contexts: site hero · cold outreach · proposal · social caption · film credit/narration · apology/problem email · invoice.

## Messaging
- Taglines: 3-5 routes, each with the idea behind it; recommend one. Avoid abstract trio words ("passion, impact, innovation").
- Pitches: 10 s (one sentence), 30 s, 60 s. Each uses the same promise and one proof point.
- Pillars (3-4): theme · key message · proof · where it shows up.
- Audience-specific lines: one per audience (client, funder, press, peers).
- Bio set: 1 line, 50 words, 150 words (third person and first person).
- Banned list: words/phrases and why. Include generic AI-sounding terms (`anti-ai-writing-filter` lists).

## Language
If two languages: decide which leads where; write each natively; list terms that stay untranslated (film titles, names).

## Quality pass
Run all copy through `anthropic-skills:anti-ai-writing-filter`. Then read each pitch aloud for rhythm. For existing voice analysis on connected platforms, `brand-voice:guideline-generation` can supply extracted patterns.
